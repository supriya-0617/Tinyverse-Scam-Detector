## 2. Module Specifications & Function Contracts

### 2.1 `src/features.py` (Implemented in Milestone 2)

#### Constants
- `MAX_MESSAGE_LENGTH: int = 2000`
- `SUSPICIOUS_TLDS: tuple[str, ...] = (".xyz", ".top", ".club", ".site", ".online", ".click", ".loan", ".work", ".vip")`
- `URL_SHORTENERS: tuple[str, ...] = ("bit.ly", "tinyurl.com", "t.co", "is.gd", "rb.gy", "cutt.ly", "t.me", "shorturl.at")`

#### Dataclass: `InputValidationResult`
```python
@dataclass
class InputValidationResult:
    is_valid: bool
    cleaned_text: str
    warnings: list[str]
    error_message: Optional[str] = None
```

#### Functions
1. `validate_message_input(text: object, max_length: int = MAX_MESSAGE_LENGTH) -> InputValidationResult`
   - **Contract:** Accepts any object, verifies it is a non-empty `str`, strips surrounding whitespace, truncates safely if length exceeds `max_length` (recording a warning), and returns an `InputValidationResult`. Never raises unhandled exceptions on malformed input.
2. `deobfuscate_token(token: str) -> str`
   - **Contract:** Converts leetspeak substitutions (`0->o`, `1->i`, `3->e`, `4->a`, `5->s`, `@->a`, `$->s`) only when a token mixes alphabetic characters with leet symbols/digits or matches known obfuscated patterns, preserving pure numeric amounts and codes.
3. `extract_text_signals(text: str) -> dict[str, bool]`
   - **Contract:** Inspects raw text and returns boolean flags: `has_url`, `has_short_url`, `has_suspicious_tld`, `has_ip_url`, `has_apk_mention`, `has_obfuscation`, `has_currency`, `has_otp_mention`, `has_protective_warning`.
4. `normalize_text(text: str, include_structural_tags: bool = True) -> str`
   - **Contract:** Applies NFKC normalization, strips zero-width characters, compacts dotted acronyms (`K.Y.C` -> `kyc`), appends de-obfuscated companion words for obfuscated tokens, lowercases, normalizes whitespace, and optionally appends structural signal tags (`__short_url__`, `__protective_warning__`, etc.).
5. `build_feature_vectorizer(word_max_features: int = 3000, char_max_features: int = 4000) -> FeatureUnion`
   - **Contract:** Returns an unfitted Scikit-learn `FeatureUnion` combining `word_tfidf` (`ngram_range=(1, 2)`, `sublinear_tf=True`) and `char_tfidf` (`analyzer="char_wb"`, `ngram_range=(3, 5)`, `sublinear_tf=True`).

### 2.2 `src/classifier.py` (Implemented in Milestone 2)

#### Constants
- `VALID_LABELS: set[str] = {"SCAM", "SAFE"}`
- `VALID_CATEGORIES: tuple[str, ...] = ("KYC/Bank", "Lottery/Prize", "Loan/Credit", "Job/Investment", "Other")`
- `REQUIRED_COLUMNS: tuple[str, ...] = ("text", "label", "category", "source", "language")`
- `RANDOM_SEED: int = 42`

#### Dataclasses
```python
@dataclass
class DatasetValidationReport:
    total_rows: int
    scam_count: int
    safe_count: int
    duplicate_count: int
    missing_value_count: int
    category_counts: dict[str, int]
    language_counts: dict[str, int]
    source_counts: dict[str, int]
    warnings: list[str]
    is_valid: bool

@dataclass
class PredictionResult:
    verdict: Optional[str]          # "SCAM", "SAFE", or None if invalid input
    category: Optional[str]         # One of VALID_CATEGORIES if SCAM, else None
    confidence: float               # 0.0 to 100.0 percentage
    scam_probability: float         # 0.0 to 1.0 raw/calibrated probability
    reasons: list[str]              # Human-readable explanation bullets
    warnings: list[str]             # Validation / experimental calibration notices
    is_valid: bool = True
    indicators: list[dict] = field(default_factory=list)
    model_version: str = "1.0.0-m2-ml-baseline"

    def to_dict(self) -> dict[str, Any]: ...
```

#### Functions & Classes
1. `load_and_validate_dataset(csv_path: str | Path, deduplicate: bool = True) -> tuple[pd.DataFrame, DatasetValidationReport]`
   - **Contract:** Reads CSV, verifies all 5 required columns exist, checks for missing texts/labels, verifies `SAFE` rows have empty categories and `SCAM` rows have valid categories in `VALID_CATEGORIES`, checks/removes duplicate texts, and returns the cleaned DataFrame plus a structured `DatasetValidationReport`.
2. `split_dataset(df: pd.DataFrame, random_state: int = RANDOM_SEED) -> tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame]`
   - **Contract:** Performs a deterministic stratified 70% Train / 15% Validation / 15% Test split using a composite stratification key (`label + "_" + category`) so every scam category and `SAFE` class is proportionally represented in all three splits without data leakage.
3. `train_scam_detector(train_df: pd.DataFrame, val_df: pd.DataFrame, random_state: int = RANDOM_SEED) -> dict[str, Any]`
   - **Contract:**
     - Fits the `FeatureUnion` TF-IDF vectorizer **strictly on `train_df`**.
     - Trains Stage-1 Binary `LogisticRegression` (`C=2.0`, `class_weight="balanced"`, `random_state=42`) and calibrates probabilities using `CalibratedClassifierCV` (`cv=3`, `method="sigmoid"`).
     - Selects the optimal decision threshold on `val_df` (defaulting to `0.50` or tuning to minimize `SAFE` false positives).
     - Filters `train_df` to `SCAM` rows and trains Stage-2 Category `LogisticRegression` (`C=2.0`, `class_weight="balanced"`, `random_state=42`).
     - Returns the complete model bundle dictionary containing fitted vectorizer, binary estimator, uncalibrated linear estimator (for coefficient attribution), category estimator, threshold, and metadata.
4. `evaluate_model_bundle(bundle: dict[str, Any], df_split: pd.DataFrame, split_name: str) -> dict[str, Any]`
   - **Contract:** Evaluates binary accuracy, precision, recall, F1, confusion matrix (`TN, FP, FN, TP`), `SAFE` false-positive rate (`FP / (FP + TN)`), `SCAM` false-negative rate (`FN / (FN + TP)`), and category macro-F1 / per-category metrics on the given split.
5. `save_model_bundle(bundle: dict[str, Any], output_path: str | Path) -> Path` & `load_model_bundle(model_path: str | Path) -> dict[str, Any]`
   - **Contract:** Saves and loads the model bundle locally via `joblib.dump` / `joblib.load` after verifying path safety and artifact schema keys.

### 2.3 `train.py` (Implemented in Milestone 2)
- `run_training_pipeline(data_path: Path, model_path: Path, reports_dir: Path) -> dict[str, Any]`
  - Orchestrates read-only dataset validation on `data/sample_messages.csv`, stratified splitting, model training, validation/test evaluation, latency/size measurement, confusion matrix PNG generation, and saving `models/scam_detector.joblib`, `reports/evaluation_report.json`, and `reports/evaluation_summary.md`.

---

### 2.4 `predict.py` (Implemented in Milestone 2)
- `predict_message(text: object, model_path: Optional[ str | Path ] = None) -> PredictionResult`
  - Loads the cached local model bundle from `models/scam_detector.joblib`, validates input, normalizes text, computes Stage-1 binary verdict and Stage-2 category (only if `SCAM`), extracts top human-readable feature reasons, and returns `PredictionResult`.

### 2.5 Implemented Modules Across Milestones 3, 4 & 6
- **`src/rules.py` (Implemented — Milestone 3):** Implements `RuleMatch`, `RuleEvaluationResult`, and `evaluate_rules(text: object) -> RuleEvaluationResult` containing 9 modular suspicious rules (`R-CRED-01`, `R-FEE-01`, `R-LOT-01`, `R-KYC-01`, `R-LOAN-01`, `R-JOB-01`, `R-OTH-01`, `R-URL-01`, `R-OBF-01`, `R-URG-01`) and 6 contextual safe-message dampeners (`S-OTP-01`, `S-BNK-01`, `S-UPI-01`, `S-DLV-01`, `S-LJK-01`, `S-PER-01`), combined with `src/classifier.py` via `combine_ml_and_rules()` in `predict.py`.
- **`app.py` (Implemented — Milestone 4):** Implements `main()`, `analyze_user_message()`, `load_evaluation_report()`, and `get_safety_recommendation()`, rendering the local Streamlit dashboard bound to `127.0.0.1:8501`.
- **`src/privacy_audit.py` (Implemented — Milestone 6):** Implements `AuditCheckItem`, `PrivacyAuditReport`, and `run_privacy_audit(project_root: Path) -> PrivacyAuditReport` inspecting AST imports, inference write calls, remote UI assets, Streamlit config, dependencies, and runtime socket/file-write isolation.
